# 前端数据源核对报告（2026-04-01）

## 1. 核对范围
- 前端代码：`fronted/src/components/*`、`fronted/src/legacy/*`
- 文档基线：`doc/08_前后端API协议.md`（核对前版本）

## 2. 核对结论
原文档与当前前端实现存在明显偏差，主要是“文档偏 `/api/*`，实现以 Legacy Contract 接口为主”。  
已完成修订：`doc/08_前后端API协议.md` 已按真实调用全量更新。

## 3. 前端显示数据源总览

### 3.1 新版页面数据源
- `/api/orders`
- `/api/orders/{orderNo}`
- `/api/orders/{orderNo}/materials`
- `/api/materials/{parentMaterialCode}/children`
- `/api/orders/{orderNo}/materials/refresh`
- `/api/orders/{orderNo}/self-made-materials/refresh`
- `/api/inventory/refresh`
- `/api/orders/{orderNo}/reports`
- `/api/orders/{orderNo}/capacity`

### 3.2 Legacy 页面数据源
- `/queries/*`（版本、任务、订单池、规则、告警、审计）
- `/v1/mes/*`（报工、工艺路线、设备）
- `/v1/reports/*`（周报/月报及导出）
- `/internal/v1/internal/*`（订单池详情/清单/展开、主数据、排期规则、命令、模拟、集成收发箱）
- `/api/reportings`、`/api/schedules/generate`、`/api/test/*`

### 3.3 开发态数据文件
- 新版 API 数据：`src/lib/mock-service.ts`
- Legacy API 数据：`src/lib/legacy-mock-backend.ts`
- 基础样例：`src/lib/mock-data.ts`、`src/lib/mock-data.extra.ts`

## 4. 关键不一致项（已在 08 文档修正）
- 不一致 1：文档未覆盖大量 Legacy 实际接口（`/queries`、`/internal/v1/internal`、`/v1/*`）
- 不一致 2：命令返回结构并非完全统一为 `{ success, message }`，存在 `{ ok: true }`
- 不一致 3：导出接口（`/v1/reports/*/export`）在页面已使用但文档缺失
- 不一致 4：测试工具接口（`/api/test/*`）在页面可见但文档缺失

## 5. 后续维护要求
当新增或修改页面显示数据源时，必须同步更新：

1. `doc/08_前后端API协议.md`
2. 对应前端调用 client（`src/lib/api.ts` 或 `src/legacy/features/*`）
3. Mock 实现（`mock-service.ts` 或 `legacy-mock-backend.ts`）
