# 页面与用户流程

## 1. 生产订单列表页
### 页面目标
展示订单池，供用户筛选并进入订单详情。

### 用户动作
- 查询订单
- 选择订单
- 进入订单详情

## 2. 生产订单详情页
当前已抽象为 4 个 tab。
- `详情`
- `清单`
- `报工`
- `产能`

### 2.1 详情 tab
#### 目标
展示订单基础信息与关键属性。

#### 核心内容
- 订单号
- 产品信息
- 计划信息
- 状态信息

### 2.2 清单 tab
#### 目标
展示生产用料清单与自制子物料展开结构。

#### 默认行为
- 首次进入时加载根层子物料清单
- 不自动递归加载自制子物料下级 BOM

#### 表格字段
- 生产订单号
- 子项物料编码
- 子项物料名称
- 规格型号
- 应发数量
- 用量分子
- 用量分母
- 子项单位
- 物料属性
- 即时库存

#### 顶部按钮语义
- `刷新子物料`：刷新当前订单根层子物料清单，并更新缓存
- `刷新自制`：刷新当前页面已识别的自制子物料展开缓存
- `刷新库存`：刷新库存缓存，再回填当前清单的库存列

#### 行内动作
- 自制物料显示 `+`
- 点击 `+`：按当前行 `child_material_code` 作为 BOM 父项编码查询已审核 BOM，展开下一层子物料
- 点击 `-`：折叠已展开子树

### 2.3 报工 tab
#### 目标
展示当前订单历史报工数据。

#### 核心内容
- 报工时间
- 工序
- 车间
- 产线
- 数量
- 操作人

### 2.4 产能 tab
#### 目标
展示与当前订单相关的工序、车间、产线对应及产能信息。

## 3. 页面异常语义
### 清单加载中
- 表示根层子物料查询尚未返回
- 不应用“永久加载中”掩盖后端错误

### 即时库存显示“未知”
- 表示缓存中无该物料库存数据
- 不应隐式触发 ERP 全量刷新

### 自制展开为空
- 应区分两种情况
  - ERP/BOM 查询无结果
  - 后端错误导致未返回数据

## 4. 重写建议
- 前端将页面拆成 `page -> tab -> query panel -> table tree`
- 每个按钮对应单独的 mutation，不复用模糊命令
- `清单` tab 使用树表模型，根层与展开层统一渲染，不统一查询
