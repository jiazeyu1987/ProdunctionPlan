# 前端重写需求说明

## 1. 目标与范围

本文用于梳理当前系统前端已经承载的页面需求，作为前端重写时的信息架构与页面职责基线。

本文只描述前端视角内容：
- 页面与页面之间如何进入、跳转、返回
- 每个页面负责什么
- 页面内部有哪些主要分区、标签页、弹窗、表格、筛选区
- 哪些页面是正式业务页，哪些只是占位或测试页

本文不展开：
- 前后端接口字段映射
- 后端表结构
- 数据来源、同步链路、缓存关系
- 接口契约细节

---

## 2. 当前前端整体结构

当前前端是一个登录后进入业务壳层的单页应用，整体结构可以概括为：

1. 认证入口
2. 登录后的左侧导航 + 右侧内容区
3. 按角色显示不同菜单
4. 业务页面内部再通过标签页、弹窗、详情面板完成二级和三级操作

当前可见的顶层业务入口有：
- 生产订单
- 月历排期
- 排产看板
- 当日产能
- 产能审计
- 订单汇总
- 报工
- 主数据
- 测试工具

其中还有一组旧导航路径目前只是重定向或占位，不承载实际页面内容：
- `/dashboard`
- `/workbenches`
- `/tasks`
- `/schedule/board`
- `/reports/plans`
- `/schedule/versions`
- `/dispatch/commands`
- `/alerts`
- `/audit/logs`
- `/ops/integration`
- `/guide`

重写时建议不要把这些占位路由直接继承过去，而应先明确是否保留为正式功能。

## 3. 页面关系总览

### 3.1 一级关系

```text
登录/注册
  -> 进入业务首页（按角色落到第一个有权限的页面）

排产员默认首页
  -> 生产订单

车间主任默认首页
  -> 当日产能
```

### 3.2 业务页面主干关系

```text
生产订单列表
  -> 订单详情（同页内切换为详情态）
  -> 主数据页（点击产品）

订单详情
  -> 返回生产订单列表
  -> 主数据页（点击产品）
  -> 工序时序弹窗

月历排期
  -> 加载历史版本弹窗
  -> 缺料明细弹窗
  -> 日期详情面板

主数据
  -> 工艺路线标签
  -> 设备拓扑标签
  -> 主任配置标签
  -> 设备台账标签
  -> 数据备份标签

报工
  -> 产能对比弹窗

排产看板 / 订单汇总 / 当日产能 / 产能审计
  -> 目前主要是独立分析或维护页面，没有明显跨页深跳
```

### 3.3 关键跨页跳转

- 从生产订单列表点击订单号，进入同一路由下的订单详情态
- 从生产订单列表点击产品，跳到主数据页并带产品定位
- 从订单详情点击产品，跳到主数据页并带产品定位
- 主数据页在带 `product_code` 或 `process_code` 参数时，需要自动聚焦到对应工艺路线内容

## 4. 顶层框架需求

## 4.1 认证页

### 页面定位
系统统一入口页，承担登录与注册。

### 页面职责
- 提供登录模式与注册模式切换
- 注册时补充姓名和角色
- 登录成功后进入业务壳层
- 未登录时阻止进入业务页面

### 页面组成
- 系统标题与说明
- 登录/注册切换标签
- 表单区
- 提交按钮
- 成功提示与错误提示

### 重写时应保留的语义
- 登录与注册是同一个入口页的两种模式
- 角色选择发生在注册阶段
- 登录后菜单按角色变化

## 4.2 业务壳层

### 页面定位
所有正式业务页面的统一承载容器。

### 页面职责
- 提供左侧导航
- 显示当前用户信息
- 提供退出登录
- 根据角色控制菜单显示
- 承载右侧主内容区域

### 结构要求
- 左侧固定导航
- 右侧内容区
- Lite 排程沙盘页面需要弱化常规导航，只保留返回入口

## 5. 一级业务页面需求

## 5.1 生产订单页

### 页面定位
这是当前系统最核心的业务入口，承担“订单池浏览 + 订单筛选 + 批量操作 + 单订单详情查看”。

### 页面关系
- 是排产员默认首页
- 可进入订单详情态
- 可跳转到主数据页

### 页面职责
- 展示订单池主列表
- 提供主筛选和高级筛选
- 支持分页
- 支持勾选多条订单
- 支持批量冻结、批量解冻、批量提权
- 支持单条订单操作
- 支持切换到订单详情态

### 页面主结构
- 页面标题
- 列表标签页
  - 主视图
  - 高级筛选
- 工具栏
- 分页工具条
- 订单表格
- 订单详情面板

### 列表态需要承载的能力
- 搜索订单
- 按状态筛选
- 按交期筛选
- 按车间/产线/工序筛选
- 按缺料、冻结、锁定等状态筛选
- 控制表格显示列
- 多选订单
- 执行单条命令
- 执行批量命令

### 表格层面的职责
- 订单号是详情入口
- 产品是主数据入口
- 列表需同时承担“浏览、判断风险、发起动作”三类任务
- 行内操作至少包括冻结、解冻、提权、降权、删除

### 详情态定位
订单详情不是独立新页面，而是订单页中的详情工作区。

### 详情态职责
- 展示单订单完整业务信息
- 承载四个核心标签页
- 允许返回列表

### 详情态的四个标签页

#### 1. 详情
- 展示订单基础信息
- 展示交期、优先级、状态、进度、排程结果、风险摘要
- 提供人工开工约束设置
- 展示设置后的影响预览

#### 2. 用料
- 展示物料树
- 支持根层物料刷新
- 支持自制物料展开与折叠
- 支持自制展开刷新
- 支持库存刷新
- 区分加载中、刷新中、错误、警告几种状态

#### 3. 报工
- 展示当前订单历史报工记录
- 以表格形式查看报工编号、类型、工序、数量、时间

#### 4. 资源
- 展示订单工序对应的实际资源与候选资源
- 允许点击某工序打开“工序时序详情”弹窗
- 在弹窗内查看该工序相关订单的时间展开

### 这个页面在重写时建议拆分为
- 订单列表页
- 订单详情容器
- 详情 tab
- 用料 tab
- 报工 tab
- 资源 tab
- 工序时序弹窗

## 5.2 月历排期页

### 页面定位
这是正式排产结果和排产控制的主页面，核心是“月历 + 排产设置 + 某日详情”三栏协作。

### 页面职责
- 以月历方式承载排产结果浏览
- 支持切换月份
- 支持选择某日查看详情
- 支持调整日期工作模式
- 支持排产策略选择与执行
- 支持保存当前版本
- 支持加载历史版本
- 支持推进模拟日与重置模拟

### 页面主结构
- 左侧：月历区
- 右侧上半：排产设置区
- 右侧下半：日期详情区
- 全局弹窗
  - 加载历史版本
  - 缺料明细

### 左侧月历区职责
- 展示按周展开的月历网格
- 每一天显示排产状态摘要
- 高亮当前模拟日期和选中日期
- 支持点选日期
- 支持设置日期模式

### 右侧设置区职责
- 选择排产策略
- 触发初排
- 触发重排
- 保存当前版本
- 打开历史版本加载弹窗
- 设置节假日与周末规则
- 展示提示信息和错误信息

### 右侧日期详情区职责
- 展示选中日期的排程明细
- 按车间切换查看
- 展示当日物料预估信息

### 重写时建议关注
- 这是一个复合型控制台页面，不宜拆成过多独立跳页
- 更适合重构为“左历法 + 右配置/详情”的稳定工作台

## 5.3 排产看板页

### 页面定位
面向排产员的分析看板，强调趋势、瓶颈、负荷和物料消耗。

### 页面职责
- 按时间范围查看排产整体表现
- 通过指标卡快速判断健康度
- 通过图表查看产线/工序趋势
- 通过表格查看超载、瓶颈、日期负荷、物料消耗排名

### 页面主结构
- 时间筛选工具栏
- 核心指标卡
- 驾驶舱摘要卡
- 两组趋势图表
- 多个分析表格

### 内容分区
- 核心指标
- 驾驶舱摘要
- 产线每日产能变化
- 工序每日产能变化
- 超载产线
- 瓶颈工序
- 日期负荷
- 物料消耗排行

### 重写建议
- 保持“筛选区 + 指标区 + 图表区 + 明细表区”的层次
- 适合做成偏分析中台风格页面

## 5.4 当日产能页

### 页面定位
维护某日班次级可用能力，并承接现场报工录入。

### 页面职责
- 按日期查看班次能力记录
- 编辑班次能力
- 保存整页调整
- 对单行发起班次报工
- 展示汇总指标

### 页面主结构
- 日期与操作工具栏
- 提示说明
- 汇总指标卡
- 班次能力表格

### 表格职责
- 按车间、产线、工序、班次展示能力记录
- 支持修改人数、设备数
- 展示默认能力、计划能力、实际完成量、报工次数、最近报工时间
- 在行内打开报工表单

### 行内报工职责
- 录入本班完成量
- 可带入前一日完成量
- 可提交或取消

### 重写建议
- 将“能力维护”和“班次报工”明确区分为两种交互模式
- 编辑态和报工态不能相互打架

## 5.5 产能审计页

### 页面定位
查看班次能力变更记录的审计页。

### 页面职责
- 按日期、车间、产线、工序、操作人筛选审计记录
- 支持只看发生变化的数据
- 展示变更前后对比和变化量

### 页面主结构
- 筛选工具栏
- 审计摘要卡
- 审计表格

### 表格职责
- 展示变更时间、操作人、车间、产线、工序、班次
- 展示能力、人力、设备的旧值、新值、变化量
- 展示变更类型和原因说明

## 5.6 订单汇总页

### 页面定位
按时间范围统计订单完成情况和工序完成情况的汇总分析页。

### 页面职责
- 选择时间范围
- 统计订单级汇总指标
- 统计工序级汇总指标
- 对车间主任角色展示车间主任筛选

### 页面主结构
- 时间筛选工具栏
- 指标卡
- 订单完成情况表
- 工序完成情况表

### 重写建议
- 这是标准的“汇总分析页”，结构应尽量简洁稳定
- 与排产看板不同，它更偏结果统计，不强调图表驱动

## 7. 页面关系上的关键设计结论

## 7.1 真正的核心业务主线

当前前端最清晰的业务主线其实是：

```text
生产订单
  -> 查看订单详情
  -> 查看用料/报工/资源
  -> 跳主数据确认工艺路线
  -> 回到排期相关页面做排产决策
```

以及：

```text
月历排期
  -> 查看某日排产结果
  -> 查看缺料与日期详情
  -> 保存版本 / 加载版本
```

## 7.2 复合页很多

当前前端有三类典型复合页：
- 订单页：列表与详情共存
- 月历排期页：月历、设置、详情共存
- 主数据页：多个配置中心共存在一个页面中

这意味着重写时不能只按“一个菜单一个简单 CRUD 页”的思路来做。

## 7.3 当前有明显的“页中页”

以下内容虽然不是独立路由，但本质上已经是独立子页面：
- 订单详情的四个标签页
- 主数据的五个配置标签
- 测试工具的四个验证标签
- Lite 沙盘的四个工作标签

重写时建议把它们视为“子页面模块”，在设计组件层级和状态边界时单独对待。

## 8. 前端重写建议的页面拆分方案

为了便于重写，建议把当前需求拆成下面这组前端模块：

### 8.1 基础层
- 认证页
- 应用壳层
- 角色导航系统
- 通用表格、筛选条、弹窗、状态提示

### 8.2 核心业务层
- 订单池列表模块
- 订单详情模块
- 月历排期模块
- 排产看板模块
- 当日产能模块
- 产能审计模块
- 订单汇总模块
- 报工模块

### 8.3 主数据层
- 工艺路线模块
- 设备拓扑模块
- 主任配置模块
- 设备台账模块
- 数据备份模块

### 8.4 辅助工具层
- 测试工具模块
- Lite 排程沙盘模块

## 9. 重写时建议优先确认的产品问题

这些问题不涉及后端，而是前端信息架构本身需要先定：

1. 订单详情是否继续保留为“订单页内详情态”，还是改成独立详情页。
2. 主数据是否继续保留为单页多标签，还是拆成多个独立菜单页。
3. 月历排期是否继续采用三栏工作台结构。
4. 测试工具是否保留在正式导航中。
5. Lite 排程沙盘是否保留在正式产品内。
6. 那些当前只做重定向的占位菜单，是否在重写版中删除。
7. 排产员与车间主任的首页是否仍按当前逻辑区分。

## 10. 可直接作为重写范围的结论

如果以“重写正式前端”为目标，当前最值得优先覆盖的页面范围是：

1. 认证页
2. 应用壳层
3. 生产订单页
4. 月历排期页
5. 排产看板页
6. 当日产能页
7. 产能审计页
8. 订单汇总页
9. 报工页
10. 主数据页

测试工具页与 Lite 排程沙盘页更适合视为第二阶段或内部能力。
