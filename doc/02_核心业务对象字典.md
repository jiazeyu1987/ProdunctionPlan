# 核心业务对象字典

## 1. ProductionOrder 生产订单
### 业务含义
生产执行与计划的核心业务单据。

### 建议主键
- `production_order_no`

### 关键字段
- `production_order_no`
- `material_code`
- `material_name`
- `material_specification`
- `production_qty`
- `status`
- `planned_start_date`
- `planned_end_date`
- `source_bill_no`
- `material_list_no`

## 2. MaterialIssueItem 生产用料清单项
### 业务含义
生产订单详情中展示的根层子物料项，或自制展开后的下一层子物料项。

### 建议唯一键
- 根层：`production_order_no + child_material_code`
- 子层：`parent_material_code + child_material_code`

### 关键字段
- `production_order_no`
- `parent_material_code`
- `child_material_code`
- `child_material_name`
- `spec_model`
- `issue_qty`
- `supply_type_code`
- `supply_type_name`
- `inventory_qty`
- `inventory_status`
- `usage_numerator`
- `usage_denominator`
- `child_unit`
- `source_type`
- `level`

## 3. BomHeader 物料清单头
### 业务含义
ERP 物料清单列表中的 BOM 主记录。

### 建议唯一键
- `bom_id`
- 业务唯一可补充：`parent_material_code + bom_version`

### 关键字段
- `bom_id`
- `parent_material_code`
- `parent_material_name`
- `bom_version`
- `bom_name`
- `document_status`
- `organization_code`

## 4. BomItem 物料清单明细
### 业务含义
BOM 头下的子项明细，用于自制子物料展开。

### 建议唯一键
- `bom_id + seq_no`

### 关键字段
- `bom_id`
- `seq_no`
- `child_material_code`
- `child_material_name`
- `child_specification`
- `usage_numerator`
- `usage_denominator`
- `child_unit`
- `supply_type`

## 5. InventorySnapshot 物料库存快照
### 业务含义
系统缓存的即时库存结果，不等同于 ERP 原始流水。

### 建议唯一键
- `material_code`

### 关键字段
- `material_code`
- `inventory_qty`
- `inventory_status`
- `snapshot_time`
- `source`

### 约束
- 默认只保留一个当前版本
- 不保留历史批次，除非后续明确要求审计

## 6. MaterialSupplyInfo 物料属性信息
### 业务含义
描述物料是自制、外购等属性，供页面直接展示。

### 建议唯一键
- `material_code`

### 关键字段
- `material_code`
- `supply_type_code`
- `supply_type_name`
- `organization_code`
- `snapshot_time`

## 7. WorkReport 历史报工记录
### 业务含义
订单的历史执行反馈记录。

### 建议唯一键
- `report_id`

### 关键字段
- `report_id`
- `production_order_no`
- `process_code`
- `workshop_code`
- `line_code`
- `report_qty`
- `report_time`
- `operator`
- `shift`

## 8. CapacityBinding 工序-车间-产线对应
### 业务含义
用于产能展示和计划校验的结构化关系。

### 建议唯一键
- `process_code + workshop_code + line_code`

### 关键字段
- `process_code`
- `process_name`
- `workshop_code`
- `workshop_name`
- `line_code`
- `line_name`
- `capacity_qty`
- `calendar_code`

## 9. PageQuerySnapshot 页面查询结果快照
### 业务含义
前端页面直接消费的聚合结果。

### 原则
- 可以缓存
- 不能反向作为 ERP 原始数据真源
- 必须由领域服务重新计算或重建

## 10. 重写时的建模原则
- ERP 原始对象和页面聚合对象分离
- `issue_qty`、`inventory_qty`、`supply_type` 作为正式字段建模，不再只藏在 JSON 中
- 用料清单与 BOM 展开分成两类查询模型
- 缓存表只存“当前版本”，明确唯一键
