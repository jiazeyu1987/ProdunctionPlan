# 业务域地图

## 1. 系统定位
当前系统是一个面向生产计划与执行协同的业务系统，核心目标是围绕生产订单形成“订单池 -> 用料 -> 库存/供应 -> 报工 -> 产能 -> 排程”的闭环。

## 2. 一级业务域
### 2.1 生产订单域
- 管理生产订单池
- 展示生产订单基础信息、状态、日期、来源单据
- 提供订单详情、清单、报工、产能等视图入口

### 2.2 生产用料域
- 基于生产订单生成根层子物料清单
- 支持自制子物料展开下一层 BOM 子项
- 展示子物料编码、名称、规格型号、应发数量、物料属性、即时库存等信息

### 2.3 ERP 集成域
- 从 ERP 拉取生产订单、子物料、库存、供应等数据
- 将 ERP 原始数据映射为系统内部结构
- 提供刷新、缓存、持久化恢复能力

### 2.4 库存与供应域
- 展示物料即时库存
- 展示物料属性，如自制、外购等
- 支撑物料可得性判断与后续排程约束

### 2.5 执行报工域
- 展示历史报工数据
- 将生产执行结果回连到订单视图
- 为产能分析、计划调整提供输入

### 2.6 产能与工艺域
- 展示工序、车间、产线对应关系
- 支撑计划排产、负荷分析、资源能力判断

### 2.7 主数据与配置域
- 管理路线、日历、设备拓扑、工艺配置等基础数据
- 为排程、报工、订单展示提供规则基础

### 2.8 排程与仿真域
- 根据订单、产能、约束、库存生成计划
- 支持计划版本、仿真与结果对比

## 3. 当前最核心的页面级业务链路
### 3.1 生产订单详情链路
- 进入订单详情
- 查看 `详情 / 清单 / 报工 / 产能` 四个 tab
- 在清单 tab 中查看根层生产用料清单
- 对根层物料执行 `刷新子物料 / 刷新自制 / 刷新库存`
- 对自制物料执行 `+` 展开下一层 BOM 子项

### 3.2 用料与库存联动链路
- 根层清单来自生产订单物料清单查询
- 即时库存来自库存缓存或 ERP 库存刷新
- 物料属性来自供应/物料主数据
- 页面最终展示的是业务聚合结果，不是 ERP 原始行

## 4. 重写时建议的域拆分
- `order-domain`: 生产订单、订单池、订单详情
- `material-domain`: 用料清单、BOM 展开、应发数量
- `inventory-domain`: 即时库存、库存刷新、库存快照
- `erp-gateway`: ERP 查询、字段映射、失败处理
- `report-domain`: 报工、执行历史
- `capacity-domain`: 工序/车间/产线、产能视图
- `masterdata-domain`: 主数据配置与校验
- `schedule-domain`: 计划、版本、仿真、差异
